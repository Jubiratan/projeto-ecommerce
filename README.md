# Feirinha Shop - Sistema DevOps

E-commerce de frutas frescas desenvolvido em Node.js (Express) para a atividade prática de DevOps.

## 👥 Equipe e Definição do Projeto
* **Nome do Projeto:** Feirinha Shop Express Simples
* **Descrição:** Aplicação web para cadastro de clientes e montagem de pedidos online de frutas frescas.
* **Funcionalidades:** Catálogo dinâmico via API, carrinho de compras interativo e formulário de cadastro validado.

## 🚀 Como Executar Localmente

1. Certifique-se de ter o **Node.js** instalado.
2. Na raiz do projeto, instale as dependências:
   ```bash
   npm install
3. Depois execute com "npm run dev"
